# RISCV-RV32E-Emulator

• Designed a modular RV32E RISC-V execution platform in C with fetch, decode, execute, memory, and write-back.
• Built an RV32E Instruction Set Simulator (ISS) supporting arithmetic, control flow, memory, and system instructions.
• Built a 4 KB little-endian memory subsystem supporting 8/16/32-bit accesses with alignment and bounds checking.
• Created a bare-metal RISC-V build pipeline using a custom startup file, linker script, ELF to C-array generation.
